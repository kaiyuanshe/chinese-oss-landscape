# 开源社品牌资产

本目录素材来自用户在本次开发中提供并授权用于本站的开源社品牌素材包，核验日期为 2026-10-15。官方品牌资源入口为 [开源社品牌资源](https://kaiyuanshe.cn/brand)。此处记录素材来源和加工过程，不为品牌标识另行声明开源许可证。

| 本站文件                          | 来源文件          | 尺寸       | 加工方式                                                               |
| --------------------------------- | ----------------- | ---------- | ---------------------------------------------------------------------- |
| `kaiyuanshe-horizontal.png`       | `原版/logo1.png`  | 1190 × 401 | 蓝色实心横版，原文件直接复制，保留透明背景                             |
| `kaiyuanshe-horizontal-white.png` | `白色/图层 2.png` | 1190 × 401 | 白色横版，原文件直接复制，保留透明背景；用于深色背景                   |
| `favicon.png`                     | `原版/logo4.png`  | 192 × 192  | 原图 568 × 570，等比缩放至 191 × 192，置于透明正方形画布，未拉伸或裁切 |
| `social.png`                      | `原版/logo1.png`  | 1200 × 630 | 保留原标识形状与颜色，白底排版，添加中英文站点名                       |

分享图中的站点文字为“中国开源地图”及“Chinese Open Source Landscape”，使用本地 Hiragino Sans GB 和 Arial 渲染为位图，字体文件不随站点分发。文字使用与蓝色标识一致的 `#2e709f`。Logo 未进行重绘、换色或文字替换。

两份横版原图均具有有效透明通道。白色横版的 RGB 通道均为 255，但透明度覆盖 0–255，因此它是透明背景上的白色标识，并非不透明白色矩形。
